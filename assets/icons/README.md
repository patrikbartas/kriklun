# Zdrojové ikony

Pixelové ikony zo [Streamline](https://streamlinehq.com) (Pixel set), 32 × 32.
Appka tieto súbory **nenačítava** — farbu majú zapečatenú na `#000000`, takže
by v tmavom režime zmizli. Cesty z nich sú prepísané do
`src/components/ui/pixel.tsx` ako `currentColor`. Tu ležia ako zdroj, keby
bolo treba ikonu prekresliť alebo pridať ďalšiu.

| súbor        | kde sa používa                       |
| ------------ | ------------------------------------ |
| `camera.svg` | tlačidlo `nahlásiť problém` dole     |
| `wrench.svg` | odkaz na `/info` vpravo hore         |
| `me.svg`     | odkaz na `/moje` vpravo hore         |
| `kampus.svg` | odkaz na `/kampus` vpravo hore       |
